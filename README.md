# PsyQure - Landing Page Jasa Psikologi & Kesejahteraan Mental

Website mini landing page untuk layanan kesehatan mental dan psikologi klinis **PsyQure**.

## Fitur Utama
- **Hero & Branding**: Desain visual menenangkan dengan identitas brand PsyQure.
- **Profil & Sejarah Klinik**: Perjalanan dan visi klinik.
- **Katalog Layanan Interaktif**: Konseling Individu, Konseling Pasangan, Psikologi Anak & Remaja, serta Konseling Karir.
- **Paket Investasi & Harga Transparan**: Daftar paket layanan dengan highlight badge rekomendasi.
- **FAQ Interaktif**: Pertanyaan umum seputar sesi konseling dan kerahasiaan.
- **Formulir Pendaftaran Langsung WhatsApp**: Memudahkan klien memesan jadwal sesi secara instan.
- **Fitur Bagikan (Share Modal)**: Memudahkan berbagi ke WhatsApp, X, Facebook, atau salin tautan.

## Tech Stack
- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Menjalankan Secara Lokal
```bash
# Install dependensi
npm install

# Jalankan development server
npm run dev

# Build untuk produksi
npm run build
```
Atau di Windows cukup klik ganda file `jalankan-dev.bat`.
